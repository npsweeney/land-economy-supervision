# Land Economy supervision

A repository companion for your supervision work. Read the assignment circulated separately first.

## Getting started

1. **Fork** this repository into your GitHub account.
2. In your fork, create a branch called `my-supervision` from `main`.
3. Adapt the templates, add your files and commit as you work.
4. Send your branch link to your supervisor.

## Templates

Use the files you need in [templates](templates/):

| Template | Contents |
| --- | --- |
| [Question](templates/question.md) | Question, theory and expected pattern |
| [Sources](templates/sources.md) | Data sources and definitions |
| [Analysis](templates/analysis.md) | Steps to reproduce the analysis |
| [Outputs](templates/outputs.md) | Index of figures and tables |
| [Report](templates/report.md) | Findings and interpretation |
| [Workflow](templates/workflow.md) | Decisions, checks and tools |

## Quarto website

The [Quarto template](quarto/) provides a starting point for presenting multidimensional data through text, charts, maps and interactive views.

## Working locally

After forking, replace `YOUR-USERNAME` with your GitHub username:

```sh
git clone https://github.com/YOUR-USERNAME/land-economy-supervision.git
cd land-economy-supervision
git switch -c my-supervision
# Edit your files.
git add .
git commit -m "Add my work"
git push -u origin my-supervision
```
