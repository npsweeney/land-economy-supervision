# Quarto website

Edit [index.qmd](index.qmd) with your name, title and content.

With [Quarto installed](https://quarto.org/docs/get-started/), run from this folder:

```sh
quarto preview
```

Run `quarto render` to build the site in `_site/`. See [Quarto interactivity](https://quarto.org/docs/interactive/) for interactive charts and maps.
